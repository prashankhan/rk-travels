# Brand asset usage

All logo files are the approved originals (PNG). Never redraw, trace, recolour, stretch, crop or add a tagline. The stacked logo was rejected and is not included.

| File (`public/brand/`) | Use |
| --- | --- |
| `logos/rk-travels-logo-full-colour.png` | Primary. Website header and footer, documents, business card, social templates. Transparent. |
| `logos/rk-travels-logo-full-colour-on-white.png` | Where transparency is not supported (email signatures). |
| `logos/rk-travels-logo-reversed-on-navy.png` | Full colour on navy: social covers, merchandise. Not on the website. |
| `logos/rk-travels-logo-reversed-white-on-navy.png` | One-colour reversed (vinyl, embroidery). |
| `logos/rk-travels-logo-mono-navy.png`, `…-mono-black.png` | One-colour print, stamps, watermarks. |
| `logos/rk-travels-logo-navy-on-yellow.png` | Signage and promotional pieces. |
| `marks/rk-travels-favicon.png` | Favicon and app icon (also `src/app/icon.png`, `apple-icon.png`). Use instead of the full logo below 120px wide. |
| `marks/rk-travels-social-profile.png` | Social profile picture (Facebook, Instagram, WhatsApp Business, Google Business Profile). Do not redesign. |

Clear space and minimum size (proposed, not from the original brand files): keep space equal to the height of the "R" around the logo; below 120px wide, use the favicon mark.
